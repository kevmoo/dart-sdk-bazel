This directory contains local copies of packages used by google3 Dart and
Flutter apps. Many of these packages are published on https://pub.dev/.

For help on adding packages to this directory, see
http://go/thirdpartydart.

For general information on third-party libraries in google3, see
http://go/thirdparty.

If you are looking for an index of Flutter plugins, see
http://go/flutter-plugins.
